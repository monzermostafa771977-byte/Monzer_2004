# Monzer App - الإصدار الذكي المتكامل v16 Ultimate (Offline Ready - PWA)

نظام شامل ومطور لإدارة الحضور والانصراف، الإجازات، السهر، والضرائب والأرباح السنوية. يعمل بالكامل بدون إنترنت.

## 🌟 ميزة العمل بدون إنترنت (Offline Mode):
- تم دمج **Service Worker** وتقنيات التخزين المؤقت (PWA Caching)، مما يتيح للتطبيق العمل بكفاءة تامة وسلاسة مطلقة حتى عند إغلاق الإنترنت تماماً.

## 📲 طريقة التثبيت على الهاتف:
1. قم بفك ضغط ملف `Monzer_App_v16_Offline_Ready.zip`.
2. افتح ملف `index.html` في متصفح الهاتف (Chrome أو Safari).
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليثبت كتطبيق مستقل يعمل بدون إنترنت نهائياً.

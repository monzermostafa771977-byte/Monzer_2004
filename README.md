# Monzer App - الإصدار الذكي التفاعلي المتكامل v14 Ultimate (Ramadan Corrected)

نظام شامل ومطور خصيصاً لإدارة الحضور والانصراف، الإجازات، السهر، الورديات، وشرائح الضرائب والأرباح السنوية. تم تعديل شهر رمضان ليكون يوم عمل رسمي عادي (الانصراف 2:00 م) بدون مقابل إضافي، وتخصيص المقابل المادي لسهر رمضان فقط (من 2:00 م إلى 7:00 م).

## كيفية التثبيت على الهاتف:
1. قم بفك ضغط ملف `Monzer_App_v14_Ramadan_Corrected.zip` على هاتفك.
2. افتح ملف `index.html` في متصفح Google Chrome أو Safari.
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليعمل كتطبيق مستقل.

# Monzer App - الإصدار الذكي المتكامل v15 Ultimate (Fixed Overtime Engine)

نظام شامل ومطور خصيصاً لإدارة الحضور والانصراف، الإجازات، السهر، الورديات، وشرائح الضرائب والأرباح السنوية.

## 🌟 التحديث الجديد (v15):
- **قيمة سهر ثابتة وموحدة:** إمكانية حفظ قيمة مالية ثابتة ليوم السهر لمرة واحدة فقط، ليتم تطبيقها تلقائياً على كافة أيام السهر المسجلة بضغطة زر دون الحاجة لإعادة كتابة المبلغ كل يوم.
- **تطبيق مرن:** يمكنك تغيير القيمة الثابتة في أي وقت أو تخصيص يوم معين عند الحاجة.

## 📲 طريقة الفتح والتثبيت على الهاتف:
1. قم بتحميل الملف المضغوط `Monzer_App_v15_Fixed_Overtime.zip`.
2. قم بفك الضغط عن الملف في مجلد الملفات (Files).
3. افتح ملف `index.html` في متصفح الهاتف (Chrome أو Safari).
4. اضغط على خيارات المتصفح واختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليعمل كتطبيق كامل ومستقل!

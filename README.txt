تحديث نظام الحضور والتذكير الصوتي - الإصدار النهائي (V5)
=========================================================
- تم دمج الواجهة بالكامل في صفحة رئيسية مرنة واحدة لا تغلق أو تقيد المستخدم نهائياً.
- جعل التنبيهات والصوت "نظام تذكير اختياري" يفتح فقط عند رغبة المستخدم عبر لوحة منسدلة.
- ضمان فتح التطبيق فوراً على أزرار الحضور والانصراف بدون أي إجبار على شاشات أخرى.
